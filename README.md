# 🛒 Sistema de Gestión de Tienda Pro
Sistema de control de inventario desarrollado en **C#** con **.NET 8** y **Windows Forms**.

## 🚀 Características
- **CRUD Completo:** Añadir, editar, ver y eliminar productos.
- **Buscador Inteligente:** Filtro en tiempo real por nombre de producto.
- **Persistencia de Datos:** Guardado automático en archivos planos para evitar pérdida de información.
- **Interfaz Responsiva:** Diseño adaptativo que se ajusta a cualquier tamaño de ventana.
- **Cálculo de Inventario:** Visualización del valor total de la mercancía en tiempo real.

## 🛠️ Tecnologías
- Lenguaje: C#
- Framework: .NET 8.0 (Windows Forms)
- Paradigma: Programación Orientada a Objetos (POO)
